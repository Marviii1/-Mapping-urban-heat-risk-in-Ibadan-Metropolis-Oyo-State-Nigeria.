# Limitations

- Landsat thermal resolution is coarser than many urban planning decisions require.
- Cloud contamination and acquisition timing can affect dry-season comparability.
- Rural reference pixel selection should be validated manually for Ibadan's peri-urban landscape.
- Spatial autocorrelation results depend on grid resolution and spatial weights definition.
- GWR can be unstable with collinear predictors or sparse observations.
- HVI weights are assumptions unless calibrated with local evidence or stakeholder review.
